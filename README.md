# ANTIGRAVITY

ANTIGRAVITY is a production-grade AI Study Helper focused on modular architecture and scalable performance.

## Core Architecture
- **Frontend**: React-based SPA with glassmorphic UI tokens.
- **Backend**: FastAPI microservices for orchestration and user management.
- **AI Layer**: Groq-accelerated LLM pipeline with FAISS vector retrieval.

## Technical Specifications
- **Search**: Hybrid RAG with optimized chunking heuristics.
- **State**: Ephemeral session-based retriever store.
- **Security**: JWT-based authentication and filename sanitization.
